# Roadmap

TwinGrid ships in phases. Each phase is usable on its own.

## Phase 1, now: the framework (this repo)
The engine, the blank template, a step-by-step build guide, and a real redacted showcase clone. You can build and compose a clone today with Python alone.

## Phase 2, next: the MCP server
A `twingrid` MCP server so you build your clone by talking to Claude (or any MCP client). It scaffolds a grid, edits cells conversationally, validates, and composes, and the clone stays a set of files you own. No account, no hosting, runs on your machine.

## Phase 3: the web builder
A free static site where you click through the facets, fill each cell in the browser, and download your grid plus the composed prompt. The shop window, zero backend.

## Later
Grid-to-grid diffing, a migration checker for large grids, and multi-clone families (a household or a team of clones that share a core).
