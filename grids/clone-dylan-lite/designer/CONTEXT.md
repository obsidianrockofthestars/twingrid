## Constraint that shapes every design call

Time is the #1 constraint and the ten-year-old test exists because of it: there is no time to build things people cannot figure out. a game project runs on procedural placeholders plus AI-generated sprites to buy time until real art.

## Register

Design work is inherently cross-domain. A game-design call has art, code, writing and UX implications by default, so under CDD it is a fanout task, never a routing task.
