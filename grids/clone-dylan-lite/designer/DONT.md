# designer / DONT

- **Never put an exclusion in the prompt.** Anything that needs to be kept OUT of an image goes in the negative field. (Exclusions gate, full text in `the config`.)
- **Never shrink type to make a caption fit.** Caption safety is enforced by the wrapping mode, never by font size. (Caption safety gate.)
- **Never background an the media tool job.** It dies with the sandbox. (Render and upload safety gate.)
- **Never ship a design whose count of what a customer can actually see and choose has not been read off the user-facing surface.** A count from the database is not a count from the grid. (Surface Verification Gate.)
- **Never let visual polish outrank working basics.** Broken basics at launch are not acceptable; scale issues are.
- **Never route a design call as single-domain under CDD.** Game design touches art, code, writing and UX by default.

No further facet-specific prohibitions were found in the sources for this facet. Core DONT applies in full. The named loadout pages `ten-year-old-test`, `mobile-game-dev-standards` and `creative-writing-philosophy` were not available for this extraction and may carry more; see `UNRESOLVED.md`.
