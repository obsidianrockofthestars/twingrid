What's a grid

Not a black box. A page you can read.

Every trait, rule, and turn of phrase lives in a small labeled cell you can open and read. Compose a specialist, a mood, a voice, and Personakind wires the active cells into one clear identity, and tells you honestly whether it's complete before it runs. What you read is exactly what it is.

Then, if you want to get fancy, layer on your own extra grids to add more rules on top.

Power the chat

Your key stays in this browser only (localStorage) and is sent straight to Anthropic, never to us. The current composition becomes the clone's system prompt.

No key yet? Get one at console.anthropic.com. Prefer not to paste a key in a browser? Use the local runner tab.

For a fully local setup, like the way this was built: export your grid, then run the clone on your own machine with your own key. Nothing touches the web.

  1. Click Export grid below to download my-grid.json.
  2. Grab the runner from the repo: tools/personakind_chat.py.
  3. export ANTHROPIC_API_KEY=sk-ant-...
  4. python personakind_chat.py my-grid.json --specialist engineer --register surgery
